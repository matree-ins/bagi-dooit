# Automatic Tips Hemat

After onboarding, ContentView owns one automatic refresh trigger. Expense/budget changes and foreground return refresh the shared SavingsAIService. Model generation is debounced, cached per summary/day, and has a timeout. Switching tabs does not create duplicate generation or error notifications. Pull to refresh in Tips Hemat forces a retry.

The Kebiasaan kecil, lebih hemat section shows generated summary/actions automatically. During generation, unavailable model, or error, it shows deterministic fallback tips based on the dominant expense category. Empty data is a normal empty state and does not produce an error. The numerical metrics and budget status remain calculated by FinancialAdvisor. If the model produces English, it stays private until the summary and every action are translated to Indonesian with Apple Translation. No English output is displayed.

All AI errors use one root overlay toast, with readable Indonesian text, dismiss, automatic dismissal, VoiceOver announcement and retry where appropriate. No inline AI error is rendered. Error details are not displayed. Retry cooldown and a stable event ID prevent repeated toasts on rerender/tab changes. Successful retry clears the error. Background or obsolete request cancellation is silent, and late results are ignored.

SystemLanguageModel executes locally. There is no reachability gate and no cloud API or third-party request in this feature: once available, the model can work offline. If assets are not ready, the message explains enabling Apple Intelligence and connecting to finish model preparation. Actual network errors, model timeout, unsupported language/capability, unavailable assets, refusal, malformed output, and unexpected errors fall back to ordinary tips.

Run `bash Tests/run-regressions.sh`. AI-state tests use an injected mock, covering automatic deduplication, cache, connectivity error/retry, availability recovery, timeout, malformed output, cancellation, stale completions, empty data and date rollover. They simulate network failures; they do not switch a real iPhone to airplane mode. The live generation smoke check previously passed on this Mac with synthetic data in English. A separate live Apple Translation check found English–Indonesian packs installed and successfully translated the summary and both actions. Device-level validation of offline generation and toast layout/VoiceOver remains separate.


Translation uses one UI-backed Apple session per pending request. `prepareTranslation()` allows the system to request download approval if language packs are missing; no custom consent is bypassed. Installed packs work locally. Generation timeout is paused during download/permission preparation so the user can decide; a separate watchdog covers actual translation. Inactive scene transitions from system dialogs do not cancel preparation; backgrounding and data changes do. All translated strings must be present, nonempty, valid, and different from their source. Unsupported languages, missing packs, network errors, denial/cancellation, partial output and timeouts keep the Indonesian fallback and use the existing global toast. No inline translation error is rendered. The system download/consent dialog and airplane mode still require iPhone validation.
